Glosario de fundamentos

Red
Conjunto de dispositivos que pueden comunicarse.
Host
Dispositivo final conectado a una red.
IPv4
Dirección lógica de 32 bits escrita en cuatro octetos.
Máscara
Valor que separa la parte de red y la parte de host.
Prefijo CIDR
Número de bits usados para la red, por ejemplo /24.
Subred
División de una red grande en redes más pequeñas.
Switch
Conecta dispositivos dentro de una LAN.
Router
Conecta redes diferentes.
Gateway predeterminado
Puerta de salida hacia otra red, normalmente una interfaz del router.
