## UNIDAD 1
**S1 – Redes de hoy.** Componentes: hosts (clientes/servidores), dispositivos intermedios (switch, AP, router, firewall), medios (cobre/fibra/inalámbrico). Tipos: LAN, WAN, MAN, PAN, WLAN, WMAN. Acceso ISP: FTTH, HFC, DSL, móvil 4G/5G, satelital. Red convergente (datos+voz+video). Arquitectura confiable: **tolerancia a fallas, escalabilidad, QoS, seguridad**. Seguridad: confidencialidad, integridad, disponibilidad (CIA). Tendencias: IIoT, colaboración, nube, virtualización (hipervisor tipo 1/2), hogar inteligente, PLC, WISP.
**S2 – TCP/IP y capa física.** Protocolos (codificación, formato, tamaño, temporización, entrega: unicast/multicast/broadcast). OSI (7 capas) vs TCP/IP (4). **PDU**: datos → segmento → paquete → trama → bits. Encapsulación/desencapsulación. Puertos: HTTP 80, HTTPS 443, DNS 53, SSH 22, MySQL 3306. TCP (orientado a conexión) vs UDP. Organismos: ISOC, IAB, IETF, IRTF, ICANN, IANA, IEEE, EIA, TIA, ITU-T. Capa física: componentes/codificación/señalización; ancho de banda, latencia, rendimiento, goodput; cobre (UTP/STP/coaxial, atenuación, EMI/RFI, crosstalk), UTP directo/crossover/consola, T568A/B, categorías; fibra (monomodo vs multimodo, conectores ST/SC/LC); inalámbrico (802.11, 802.15, 802.16, Zigbee).

## UNIDAD 2
**S3 – IPv4 y subredes.** Direcciones lógicas (L3, IP, no cambian extremo a extremo) vs físicas (L2, MAC, cambian salto a salto). Default gateway. IP: sin conexión, mejor esfuerzo, independiente del medio; MTU/fragmentación. Cabecera IPv4 (versión, DS/ToS, checksum, TTL, protocolo, IPs 32 bits). Parte de red/host con máscara; **AND lógico**; prefijo /n; dirección de red, broadcast, hosts (**hosts = 2^h − 2**). Clases A–E (histórico), públicas vs privadas RFC1918 (10/8, 172.16/12, 192.168/16), NAT, loopback 127/8, APIPA 169.254/16, IANA→RIR→ISP. Dominios de broadcast: solo el router los separa. Subnetting en límite de octeto y en /24 (/25–/30), subredes = 2^s. Ejemplo ISP 172.16.0.0/22 con 5 sitios (/26). Ejercicios: hallar red/broadcast/primera/última IP.
**S4 – VLSM y diseño.** VLSM = subnetear una subred; **procedimiento**: (1) ordenar LAN de mayor a menor, (2) bits de host mínimos (2^n−2), (3) subnetear, (4) asignar primera subred a la mayor, repetir con las libres; enlaces WAN = /30. Ejemplos: 192.168.20.0/24 (/27 + /30), 192.168.10.0/24 con 60/25/10/5 hosts → /26, /27, /28, /29 y WAN /30. Planificación: DHCP para usuarios, IP estática para servidores, DMZ pública, gateway, administración. Tabla de entrega: subred, prefijo, red, broadcast, utilizables, máscara, gateway.

## UNIDAD 3
**S5 – Switching y VLAN.** Ethernet (subcapas LLC 802.2 / MAC 802.3). Tabla MAC (aprende MAC origen+puerto; inunda si destino desconocido/broadcast). Dúplex/velocidad, autonegociación, Auto-MDIX. **ARP** (IPv4→MAC; `show ip arp`, `arp -a`; ARP spoofing). Dominios de colisión (los elimina el switch/full-duplex) vs broadcast (router). Store-and-forward vs cut-through. VLAN: beneficios, tipos (default 1, datos, nativa, gestión, voz), troncales 802.1Q (tag 4 bytes, TPID 0x8100, VID 12 bits), rangos normal 1–1005 / extendido 1006–4095, vlan.dat. **Comandos**: `vlan 10`/`name`, `switchport mode access`, `switchport access vlan 10`, `switchport mode trunk`, `switchport trunk native vlan 99`, `switchport trunk allowed vlan ...`, `show vlan brief`, `show interfaces trunk/switchport`, `no vlan`, `delete flash:vlan.dat`. **Inter-VLAN**: legacy, **router-on-a-stick** (subinterfaces `interface fa0/0.10`, `encapsulation dot1Q 10`, `ip address`, `no shutdown` en la física) y **switch capa 3** (SVI `interface vlan 10`, `ip routing`; puerto enrutado `no switchport`).
**S6 – WLAN.** WPAN/WLAN/WMAN/WWAN; ITU-R, IEEE, Wi-Fi Alliance; estándares 802.11 (a/b/g/n/ac/ax) 2.4 y 5 GHz; AP autónomo vs LAP+WLC; antenas omni/direccional/MIMO; ad hoc/infraestructura/tethering; BSS/ESS; asociación (descubrir, autenticar, asociar; pasivo/activo); **CSMA/CA** (RTS/CTS/ACK); DSSS/FHSS/OFDM; canales no solapados 1, 6, 11 (2.4 GHz). Amenazas: intercepción, intrusos, DoS/DDoS, AP falso, MITM. Seguridad: ocultar SSID, filtro MAC, abierta vs clave compartida, WEP→WPA(TKIP)→WPA2(AES/CCMP)→WPA3(SAE), Personal(PSK) vs Enterprise(RADIUS 802.1X, UDP 1812/1813).

## UNIDAD 4
**S9 – Enrutamiento estático.** Router = computadora (CPU, IOS, RAM/ROM/NVRAM/flash). Tabla de enrutamiento: códigos **L, C, S, R, \***; redes conectadas (C, L=/32) vs remotas (estáticas o dinámicas); ruta por defecto 0.0.0.0/0 ("gateway of last resort"); métrica (RIP saltos, OSPF costo, EIGRP BW/delay); equilibrio de carga; **distancia administrativa** (conectada 0, estática 1, EIGRP 90, OSPF 110, RIP 120). `ip route <red> <máscara> <siguiente-salto|interfaz> [AD]`; tipos: siguiente salto, conectada directa (solo seriales punto a punto), totalmente especificada; estática estándar/por defecto/**flotante** (AD mayor = respaldo)/resumida. Método: listar redes conectadas, luego las NO conectadas y crear una ruta por cada una. Verificar: `show ip route [static]`, ping, traceroute, `show running-config | section ip route`.
**S10 – Enrutamiento dinámico / RIPv2.** AD y fuentes de ruta; protocolos (RIP, OSPF, EIGRP, IS-IS); convergencia; estático vs dinámico (comparación). **RIP**: `router rip`, `version 2`, `network x.x.x.x` (solo redes directamente conectadas), `no auto-summary`, interfaces pasivas (`passive-interface`), propagar default: `ip route 0.0.0.0 0.0.0.0 <ISP>` + `default-information originate`; update timer 30 s; `show ip protocols`.
**S11/12 – WAN.** Propósito, topologías (punto a punto, estrella/hub-and-spoke, malla completa, doble conexión), modelo OSI (L1/L2), términos (CPE, DCE, DTE, demarcación, bucle local/última milla, CO, troncal), dispositivos (módem, CSU/DSU, router), conmutación de circuitos vs paquetes; opciones privadas (línea arrendada, **WAN Ethernet**, **MPLS**, VSAT) y públicas (DSL, cable, inalámbrico, 4G/LTE, **VPN**); SONET/SDH, DWDM. Punto a punto serial: **HDLC** (por defecto Cisco; `encapsulation hdlc`), troubleshooting (`show interfaces serial`, `show controllers`), **PPP** (LCP, NCP, LQM, multilink, compresión), autenticación **PAP** (texto plano) vs **CHAP** (hash, 3 vías): `encapsulation ppp`, `username X secret Y`, `ppp authentication chap`, `ppp pap sent-username`.
**S13 – Capa de transporte y puertos / ACL.** TCP (sesión, confiabilidad, ventanas deslizantes, MSS 1460, congestión) vs UDP; puertos conocidos: 20/21 FTP, 22 SSH, 23 Telnet, 25 SMTP, 53 DNS, 67/68 DHCP, 69 TFTP, 80 HTTP, 110 POP3, 143 IMAP, 161 SNMP, 443 HTTPS. **ACL extendidas**: `access-list 101 deny tcp <origen> <wildcard> <destino> <wildcard> eq 80`, `permit ip any any`, `ip access-group 101 in|out` en interfaz; ACL con nombre (`ip access-list extended`), `eq` vs `range`, wildcard; ejercicios V/F de interpretación.
**S14 – IPv6 + repaso.** Escasez IPv4 (NAT/PAT), IPv6 de 128 bits, tipos (global unicast, link-local, unique local, multicast, anycast, loopback), simplificación (quitar ceros a la izquierda, `::` una sola vez). Repaso: lectura de tablas `show ip route`, y **sumarización/supernetting** (ej. 192.168.0.0–7.0/24 → 192.168.0.0/21; 10.10.0.0/18…/18 → 10.10.0.0/16; ip route resumida).
