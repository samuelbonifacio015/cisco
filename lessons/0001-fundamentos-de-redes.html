Redes Cisco · PC1 · Lección 01

Fundamentos: qué es una red, una IP y una máscara

Objetivo: entender qué significa una dirección como 192.168.10.25/24 antes de resolver subnetting.

Mapa de la lección

La idea completa en una frase

Una red conecta dispositivos. La IP identifica lógicamente a cada dispositivo y la máscara indica qué parte de esa IP representa la red y qué parte representa al dispositivo.

Red → conecta dispositivos → IP identifica → máscara separa red y host
Segmento 1 · Red

¿Qué es una red?

Una red es un conjunto de dispositivos que pueden comunicarse mediante un medio y unas reglas. El medio puede ser cable de cobre, fibra óptica o conexión inalámbrica.

PC1 ─── Switch ─── PC2

En este ejemplo, el switch conecta los dispositivos dentro de la misma red local.

Comprueba: ¿una red sirve para aislar dispositivos o para permitir su comunicación?
Permitir su comunicación.
Segmento 2 · Dispositivos

¿Qué función cumple cada dispositivo?

DispositivoFunción básica
HostEquipo final: PC, servidor, celular o impresora.
SwitchConecta equipos dentro de una LAN.
RouterConecta redes diferentes.
Access PointConecta dispositivos mediante Wi-Fi.

Regla corta: switch dentro de la red; router entre redes.

Comprueba: si una PC necesita comunicarse con otra red, ¿qué dispositivo permite salir de su red local?
El router, normalmente usando el gateway predeterminado.
Segmento 3 · Dirección IP

¿Qué es una IPv4?

Una IPv4 es una dirección lógica. Identifica un dispositivo dentro de una red.

192.168.10.25

Está formada por cuatro octetos. Cada octeto puede tener un valor entre 0 y 255.

La IP tiene dos partes:

  • Parte de red: identifica el grupo.
  • Parte de host: identifica al dispositivo dentro del grupo.
Comprueba: ¿la IP identifica físicamente el cable o lógicamente el dispositivo?
Lógicamente el dispositivo.
Segmento 4 · Máscara

¿Qué significa /24?

El prefijo /24 significa que los primeros 24 bits de la dirección pertenecen a la red. Los 8 bits restantes pertenecen a los hosts.

IP:       192.168.10.25
Máscara:  255.255.255.0
Prefijo:  /24

Red:      192.168.10
Host:                 25

Por tanto, en 192.168.10.25/24:

  • 192.168.10 identifica la red.
  • 25 identifica al host.
Comprueba: en 192.168.10.25/24, ¿qué parte corresponde al host?
El último octeto: 25.
Segmento 5 · Subred

¿Qué es una subred?

Una subred es una división de una red grande en redes más pequeñas. Cada subred tendrá una dirección de red, hosts y un broadcast.

Ejemplo conceptual:

Red grande: 192.168.10.0/24
Subredes:   192.168.10.0/26
            192.168.10.64/26
            192.168.10.128/26
            192.168.10.192/26

Todavía no calcularemos estos rangos. Primero necesitamos dominar red, host y máscara. El siguiente segmento será: dirección de red, hosts utilizables y broadcast.

Cierre

Resumen de hoy

  1. Una red permite que los dispositivos se comuniquen.
  2. El switch conecta equipos dentro de una LAN.
  3. El router conecta redes diferentes.
  4. La IP identifica lógicamente un dispositivo.
  5. La máscara separa la parte de red y la parte de host.
  6. /24 significa 24 bits de red y 8 bits de host.

Si algo no quedó claro, pregunta por el segmento concreto y lo repetimos con otro ejemplo.
