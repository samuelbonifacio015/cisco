Unidad 1 · Semanas 1–2

Conceptos básicos y modelo OSI

S1 · Redes de hoy

Componentes

  • Hosts: clientes y servidores.
  • Intermedios: switch, AP, router, firewall.
  • Medios: cobre, fibra, inalámbrico.

Tipos de red

PAN · LAN · WLAN · MAN · WMAN · WAN. La LAN es de una sola organización; la WAN conecta LANs y suele contratarse a un proveedor.

Arquitectura confiable

  • Tolerancia a fallas
  • Escalabilidad
  • QoS (prioriza voz y video)
  • Seguridad: confidencialidad, integridad, disponibilidad

Acceso a Internet

FTTH, HFC (cable), DSL, móvil 4G/5G, satelital. Red convergente = datos, voz y video sobre la misma red.

Tendencias: IoT/IIoT, colaboración en línea, nube, virtualización (hipervisor tipo 1 sobre hardware, tipo 2 sobre un SO), hogar inteligente, PLC (red por cableado eléctrico) y WISP.

Encapsulación: al bajar por las capas cada una agrega su encabezado (datos → segmento → paquete → trama → bits). El receptor desencapsula al subir.

Reglas de un protocolo

Codificación, formato, tamaño, temporización y entrega: unicast (1 a 1), multicast (1 a grupo), broadcast (1 a todos).

TCP vs UDP

TCP: orientado a conexión, confiable, ordena y retransmite. UDP: sin conexión, rápido, sin garantías (voz, video, DNS).

Organismos

ISOC, IAB, IETF, IRTF (Internet) · ICANN, IANA (direcciones) · IEEE, EIA, TIA, ITU-T (estándares).

Capa física

  • Ancho de banda = capacidad teórica; rendimiento = lo que realmente pasa; goodput = rendimiento útil sin encabezados; latencia = retardo.
  • Cobre: UTP, STP, coaxial. Problemas: atenuación, EMI/RFI, crosstalk. Cable directo (T568B–T568B) entre equipos distintos, cruzado (T568A–T568B) entre iguales, cable de consola para configurar.
  • Fibra: monomodo (láser, larga distancia) vs multimodo (LED, corta distancia). Conectores ST, SC, LC.
  • Inalámbrico: 802.11 Wi-Fi, 802.15 Bluetooth, 802.16 WiMAX, Zigbee.
Unidad 2 · Semanas 3–4

Direccionamiento IP y redes LAN

S3 · IPv4 y subredes

IP vs MAC

IP (capa 3, lógica) se mantiene de extremo a extremo. MAC (capa 2, física) cambia en cada salto. El default gateway es la IP del router en la LAN.

Características de IP

Sin conexión, mejor esfuerzo, independiente del medio. Cabecera: versión, DS, TTL, protocolo, checksum, IP origen y destino de 32 bits.

Las 4 cuentas de siempre

  • Red = IP AND máscara (bits de host en 0).
  • Broadcast = bits de host en 1.
  • Hosts = 2h − 2, donde h = bits de host. Subredes = 2s, donde s = bits prestados.
  • Salto (tamaño del bloque) = 256 − valor de la máscara en el octeto interesante.
Ejemplo: 192.168.10.66/25

Máscara 255.255.255.128, salto 128. Bloques: .0–.127 y .128–.255. La IP .66 cae en el primero → red 192.168.10.0, broadcast 192.168.10.127, hosts .1 a .126 (126 hosts).

Privadas (RFC 1918)

Dominio de broadcast

Solo el router separa dominios de broadcast. El switch no.

S4 · VLSM y diseño de direccionamiento

VLSM es subnetear una subred: cada LAN recibe solo el tamaño que necesita.

  1. Ordena las LAN de mayor a menor cantidad de hosts.
  2. Para cada una, busca los bits de host mínimos con 2h − 2 ≥ hosts.
  3. Subnetea el bloque disponible con ese prefijo.
  4. Asigna la primera subred a la LAN más grande y sigue subneteando lo libre. Enlaces entre routers = /30.
Ejemplo del curso: 192.168.10.0/24 con 60, 25, 10 y 5 hosts + 1 enlace WAN

Unidad 3 · Semanas 5–7

Switching, VLAN y WLAN

S5 · Ethernet, switching y ARP

Tabla MAC

El switch aprende la MAC origen y el puerto. Si no conoce la MAC destino, o es broadcast, inunda por todos los puertos menos el de entrada.

ARP

Traduce IPv4 → MAC con un broadcast. Ver caché: show ip arp (router) o arp -a (PC). Riesgo: ARP spoofing.

Dominios

Colisión: los elimina el switch con full-duplex. Broadcast: solo los separa el router (o las VLAN).

Reenvío

Store-and-forward revisa la trama completa (FCS). Cut-through reenvía apenas lee la MAC destino. Auto-MDIX corrige el tipo de cable.

Ethernet tiene dos subcapas: LLC (802.2) y MAC (802.3).

S5 · VLAN y enlaces troncales

Una VLAN es un dominio de broadcast lógico dentro del switch. Tipos: default (VLAN 1), datos, nativa, gestión y voz. Rango normal 1–1005 (se guarda en vlan.dat), extendido 1006–4094.

El trunk 802.1Q lleva varias VLAN por un cable: inserta una etiqueta de 4 bytes (TPID 0x8100, VID de 12 bits). La VLAN nativa viaja sin etiqueta.

! crear VLAN
S1(config)# vlan 10
S1(config-vlan)# name VENTAS
! puerto de acceso
S1(config)# interface fa0/1
S1(config-if)# switchport mode access
S1(config-if)# switchport access vlan 10
! troncal
S1(config)# interface g0/1
S1(config-if)# switchport mode trunk
S1(config-if)# switchport trunk native vlan 99
S1(config-if)# switchport trunk allowed vlan 10,20,99
! verificar
S1# show vlan brief
S1# show interfaces trunk

Borrar todo: no vlan 10 o delete flash:vlan.dat y recargar.

S5 · Enrutamiento entre VLAN

Hosts de VLAN distintas necesitan un dispositivo de capa 3. Tres opciones: legacy (una interfaz física por VLAN), router-on-a-stick y switch capa 3.

Router-on-a-stick

R1(config)# interface g0/0.10
R1(config-subif)# encapsulation dot1Q 10
R1(config-subif)# ip address 192.168.10.1 255.255.255.0
R1(config)# interface g0/0
R1(config-if)# no shutdown

El puerto del switch hacia el router va en trunk. El no shutdown va en la interfaz física.

Switch capa 3 (SVI)

S1(config)# ip routing
S1(config)# interface vlan 10
S1(config-if)# ip address 192.168.10.1 255.255.255.0
S1(config-if)# no shutdown
! puerto enrutado hacia el router
S1(config-if)# no switchport

Práctica en el repo: semana-8/practica-routers-on-stick.pkt y semana-7/materials/pkas de practica/9pm-router-on-stick.pkt.

Funcionamiento

Modos ad hoc, infraestructura y tethering. BSS = un AP; ESS = varios AP con el mismo SSID. Asociación: descubrir (pasivo o activo), autenticar, asociar. Acceso al medio con CSMA/CA (RTS/CTS/ACK).

Canales y AP

En 2.4 GHz los canales que no se solapan son 1, 6 y 11. AP autónomo vs LAP administrado por un WLC. Antenas omnidireccional, direccional y MIMO.

Amenazas

Intercepción, intrusos, DoS/DDoS, AP falso (rogue), MITM.

Seguridad

WEP → WPA (TKIP) → WPA2 (AES/CCMP) → WPA3 (SAE). Personal usa PSK; Enterprise usa RADIUS 802.1X (UDP 1812/1813). Ocultar SSID y filtrar MAC no son seguridad real.

S9 · Enrutamiento estático

El router es una computadora especializada: CPU, Cisco IOS, RAM, ROM, NVRAM y flash. Elige la mejor ruta mirando su tabla de enrutamiento.

Menor AD = más confiable. La métrica solo compara rutas de la misma fuente: RIP cuenta saltos, OSPF usa costo y EIGRP usa ancho de banda y retardo.

Método del curso

  1. Lista las redes conectadas del router.
  2. Lista las redes que no están conectadas.
  3. Escribe una ip route por cada red remota.
! siguiente salto (la IP del vecino directo)
R1(config)# ip route 192.168.2.0 255.255.255.0 10.0.0.2
! interfaz de salida (solo seriales punto a punto)
R1(config)# ip route 192.168.2.0 255.255.255.0 s0/0/0
! por defecto (router stub con una sola salida)
R1(config)# ip route 0.0.0.0 0.0.0.0 10.0.0.2
! flotante: mismo destino, AD mayor = respaldo
R1(config)# ip route 192.168.3.0 255.255.255.0 10.0.0.10 5

Tipos de estática

Estándar · por defecto (0.0.0.0/0, "gateway of last resort") · flotante (respaldo con AD mayor) · resumida.

Verificar

show ip route · show ip route static · show running-config | section ip route · ping · traceroute.

Erratas de la diapositiva: dice R1#ip route 0.0.0.0 0.0.0.0 10.0.3.2 29. El comando va en R1(config)#, y el 29 final es la AD, no una máscara: esa ruta por defecto es flotante.

S10 · Enrutamiento dinámico y RIPv2

Estático

Lo escribes tú. Sin consumo de CPU, seguro y predecible. No se adapta si cae un enlace. Bueno para redes pequeñas y routers stub.

Dinámico

Los routers comparten rutas. Se adapta solo (convergencia). Usa CPU y ancho de banda. Protocolos: RIP, OSPF, EIGRP, IS-IS.

R1(config)# router rip
R1(config-router)# version 2
R1(config-router)# network 192.168.1.0     ! solo redes conectadas
R1(config-router)# network 10.0.0.0
R1(config-router)# no auto-summary
R1(config-router)# passive-interface g0/0  ! no enviar updates a la LAN
! propagar ruta por defecto hacia el ISP
R1(config)# ip route 0.0.0.0 0.0.0.0 209.165.200.226
R1(config-router)# default-information originate
R1# show ip protocols

RIP usa saltos como métrica (máximo 15) y envía actualizaciones cada 30 s. Las rutas aprendidas aparecen con código R y [120/saltos].

S11–S12 · WAN, HDLC y PPP

Topologías WAN

Punto a punto · estrella (hub-and-spoke) · malla completa · doble conexión.

Términos

CPE, DTE (router del cliente), DCE (equipo del proveedor que da el reloj), punto de demarcación, bucle local (última milla), oficina central (CO).

Privadas

Línea arrendada · WAN Ethernet · MPLS · VSAT.

Públicas

DSL · cable · inalámbrico · 4G/LTE · VPN sobre Internet.

Conmutación de circuitos vs de paquetes. Transporte óptico: SONET/SDH, DWDM. Dispositivos: módem, CSU/DSU, router.

Enlaces seriales

HDLC es la encapsulación por defecto de Cisco. PPP agrega LCP (establece el enlace), NCP (protocolos de capa 3), calidad de enlace, multilink, compresión y autenticación.

ACL extendidas (100–199)

  • Se leen de arriba hacia abajo; la primera coincidencia gana.
  • Al final hay un deny implícito: sin permit ip any any se bloquea todo lo demás.
  • Wildcard = inverso de la máscara (255.255.255.0 → 0.0.0.255). host = 0.0.0.0, any = todo.
  • Se aplican cerca del origen con ip access-group N in|out.
! la red 192.168.10.0/24 no puede navegar por HTTP al servidor 10.1.1.10
R1(config)# access-list 101 deny tcp 192.168.10.0 0.0.0.255 host 10.1.1.10 eq 80
R1(config)# access-list 101 permit ip any any
R1(config)# interface g0/0
R1(config-if)# ip access-group 101 in
! con nombre
R1(config)# ip access-list extended BLOQUEO-WEB
R1(config-ext-nacl)# deny tcp any any range 20 21

Ejercicios V/F

Lee línea por línea con el paquete en la mano: origen, destino, protocolo y puerto. Si ninguna línea coincide, el resultado es deny.

S14 · IPv6 y sumarización

IPv4 se agotó; NAT/PAT lo alargó. IPv6 usa 128 bits en 8 grupos hexadecimales.

Tipos

Global unicast (2000::/3) · link-local (FE80::/10) · unique local (FC00::/7) · multicast (FF00::/8) · anycast · loopback ::1.

Simplificar

1) Quita los ceros a la izquierda de cada grupo. 2) Cambia una sola secuencia de grupos en cero por ::.

Ejemplo de simplificación

2001:0DB8:0000:0000:0000:FF00:0042:8329 → 2001:DB8::FF00:42:8329

Sumarización (supernetting)

  1. Pasa las redes a binario en el octeto donde cambian.
  2. Cuenta los bits iguales desde la izquierda.
  3. Prefijo = bits comunes; red = los bits comunes con el resto en 0.
192.168.0.0  → 00000|000
192.168.1.0  → 00000|001
   ...
192.168.7.0  → 00000|111
16 + 5 bits comunes = /21
Resumen: 192.168.0.0/21
R1(config)# ip route 192.168.0.0 255.255.248.0 10.0.0.2

Otro del curso: cuatro /18 desde 10.10.0.0 hasta 10.10.192.0 se resumen en 10.10.0.0/16.
