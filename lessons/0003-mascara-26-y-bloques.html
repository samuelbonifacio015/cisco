Redes Cisco · PC1 · Lección 03

La máscara /26 y los bloques

Ahora la red ya no ocupa todo el último octeto. La máscara divide ese espacio en bloques.

Segmento 1 · Cambio de máscara

De /24 a /26

En /24, los primeros 3 octetos son red y el último es host. En /26, se toman 2 bits adicionales del último octeto para crear subredes.

/24 → 255.255.255.0
/26 → 255.255.255.192

El nuevo resultado es:

26 bits = red
 6 bits = hosts
Comprueba: ¿qué máscara decimal corresponde a /26?
255.255.255.192
Segmento 2 · Tamaño del bloque

El salto se calcula así

Usamos el octeto interesante: 192.

256 - 192 = 64

El resultado, 64, es el tamaño de cada bloque. Las redes empiezan cada 64 números.

0 ───── 63 | 64 ───── 127 | 128 ───── 191 | 192 ───── 255

No confundas el tamaño del bloque con la cantidad de hosts. Cada bloque tiene 64 direcciones, pero 2 están reservadas.

Para una dirección como 192.168.20.130/26, solo miramos el último número: 130.

Comprueba: ¿en qué bloque está el número 130?
En el bloque 128–191.
Segmento 4 · Aplicación

Resolver 192.168.20.130/26

Como 130 está entre 128 y 191:

Red:          192.168.20.128
Primer host:  192.168.20.129
Último host:  192.168.20.190
Broadcast:    192.168.20.191

El procedimiento siempre es el mismo:

  1. Convertir prefijo a máscara.
  2. Calcular el salto.
  3. Ubicar la IP en un bloque.
  4. Inicio = red; final = broadcast.
  5. Los números intermedios = hosts.
