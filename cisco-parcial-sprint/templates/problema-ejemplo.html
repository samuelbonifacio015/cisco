Problema 01 · Router-on-a-stick con VLAN 667

Etapa 4 del roadmap · Sede: La Libertad · Método inter-VLAN: router-on-a-stick · Dificultad: media · Tiempo sugerido: 20 min

1. Escenario

En la sucursal La Libertad ya funciona la VLAN 21 (Ventas). Debes agregar dos PCs nuevas en la VLAN 667 (SuperBestias, red 192.168.69.0/24) y lograr que se comuniquen con la PC de Ventas existente. Todos los valores necesarios están en este documento; no hay datos que inventar ni pedir.

7. Tareas

  1. En SW_ACC1 y SW_CENTRAL: crear la VLAN 667 con nombre SuperBestias. 1 pt
  2. Asignar Fa0/10 y Fa0/11 de SW_ACC1 a la VLAN 667 (access). 1 pt
  3. Configurar IP, máscara y gateway de Prueba1 y Prueba2 según la sección 5. 1 pt
  4. Verificar con show vlan brief en SW_ACC1. 1 pt
  5. Verificar los troncales y crear la sub-interfaz Gi0/0.667. 3 pts
  6. Probar conectividad: Prueba1 → PC_Ventas1 y Prueba1 → Prueba2. 3 pts

9. Errores típicos de este problema

  • El gateway de las PCs no coincide con la IP de Gi0/0.667.
  • Falta crear la VLAN 667 en uno de los switches: el trunk la descarta.
  • Trunk solo en un extremo, o allowed vlan sin la 667.
  • Gi0/0 en shutdown, o con una IP en la interfaz física.

10. Solución (intenta primero)

Ver solución completa 
! SW_ACC1 y SW_CENTRAL
enable
configure terminal
vlan 667
 name SuperBestias
 exit
! SW_ACC1
interface range fa0/10 - 11
 switchport mode access
 switchport access vlan 667
 exit
interface gi0/1
 switchport mode trunk
! SW_CENTRAL
interface fa0/24
 switchport mode trunk
interface gi0/1
 switchport mode trunk
end
! R_LIBERTAD
configure terminal
interface gi0/0
 no shutdown
interface gi0/0.667
 encapsulation dot1Q 667
 ip address 192.168.69.1 255.255.255.0
end
copy running-config startup-config
Variante B (misma VLAN de la sede) Poner Fa0/10 y Fa0/11 en switchport access vlan 21 y dar a las PCs IPs de 10.142.46.0/24 (gateway 10.142.46.1). No se crea la VLAN 667 ni la sub-interfaz.
